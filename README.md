## Project Description

This project is a Python-based Student Course Recommendation System developed using Jupyter Notebook. It collects student information from a Google Form, reads the responses from a CSV file using the Pandas library, and generates personalized recommendations based on each student's profile.

## Features

- Reads student responses from a Google Form (CSV file)
- Displays student information
- Recommends suitable courses
- Suggests professional certifications
- Recommends career paths
- Suggests programming languages to learn
- Displays academic information such as CGPA and number of carryovers
